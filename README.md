# 100 Days of DSA

I started a **100 Days of DSA** challenge to improve my Data Structures and Algorithms skills through consistent problem-solving and daily practice.

## About

This repository contains my solutions and learning notes throughout my 100 Days of DSA journey.

The goal is to strengthen my problem-solving skills, understand common algorithmic patterns, and improve my ability to write clean and efficient Python solutions.

I am solving problems primarily using **Python 3** and documenting my learning day by day.

## Problem-Solving Approach

For each problem, I focus on:

1. Understanding the problem
2. Identifying the appropriate data structure or algorithm
3. Writing a clean Python solution
4. Analyzing time and space complexity
5. Testing the solution with different cases
6. Documenting the solution and learning
