# 100 Days of DSA 🚀

## About the Challenge

I'm taking on the **100 Days of Data Structures and Algorithms (DSA)** challenge to strengthen my problem-solving skills, improve my understanding of core computer science concepts, and build consistency through daily coding practice.

Throughout this journey, I'm solving problems using **Python**, learning different approaches, and focusing on writing efficient and understandable solutions.

- Strengthen my understanding of Data Structures and Algorithms.
- Improve logical thinking and problem-solving skills.
- Practice writing clean and efficient Python code.

- Prepare for technical interviews and coding assessments.
